# Lasphera · Ролики

1. Принять приглашение в GitHub: https://github.com/roomish-ai/lasphera-roliki/invitations
2. Поставить приложение Claude (claude.ai/download) и войти в аккаунт для роликов.
3. Открыть вкладку **Code** (`</>`) и написать: «Склонируй github.com/roomish-ai/lasphera-roliki на
   рабочий стол в папку Lasphera Ролики и проверь, что Higgsfield подключён».

Дальше просто общаешься с Claude: он связан с Higgsfield и делает ролики.
