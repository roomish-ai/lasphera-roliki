# Lasphera · Ролики — как начать (для Андрея)

1. Поставить приложение Claude (claude.ai/download), войти в аккаунт для роликов.
2. Положить эту папку на рабочий стол.
3. В приложении Claude открыть вкладку **Code** (`</>`) и выбрать эту папку.
4. Первое сообщение: «Установи ffmpeg, если его нет, и проверь, что коннектор Higgsfield доступен».
   Если Higgsfield не виден — в терминале: `claude mcp add --transport http higgsfield https://mcp.higgsfield.ai/mcp`,
   затем `/mcp` и вход в Higgsfield.
5. Google Drive for desktop: поставить и держать папку `obyekty` на Диске, чтобы ролики не жили
   только на одном компьютере.

Дальше просто: «Делаем ролик по объекту 1217, картинки в obyekty/1217-nrg-voha/ishodniki».
Правила, которые Claude соблюдает сам, — в `CLAUDE.md`.
